Política de privacidad

CheckCoast Tenerife · última actualización: 4 de octubre de 2026

CheckCoast Tenerife es una app cívica sin ánimo de lucro que informa del estado de las playas de Tenerife (cierres, avisos y calidad del agua) y de los puntos de vertido costeros catalogados. Esta página explica qué datos usa y qué hace con ellos.

Qué datos recogemos

  • Token de notificaciones push (Expo Push Token). Solo si aceptas el permiso de notificaciones: la app registra un identificador anónimo del dispositivo para poder enviarte avisos de cierres y reaperturas de playas.

Nada más. La app no recoge nombre, correo, ubicación, contactos ni ningún otro dato personal. No hay cuentas de usuario, ni analítica, ni publicidad, ni rastreadores.

Para qué se usa

El token sirve exclusivamente para enviarte notificaciones sobre el estado de las playas (por ejemplo, «Cierre de baño · Playa X»). No se usa para publicidad, perfilado ni ningún otro fin.

Dónde se guarda y con quién se comparte

  • Los tokens se almacenan en el servidor del proyecto, alojado en Oracle Cloud (UE).
  • Para entregar las notificaciones, el token se envía al servicio Expo Push Service (Expo / Expo.dev), que es quien reparte el aviso a tu dispositivo.
  • No se venden ni comparten datos con ningún otro tercero.

Contenido y fuentes

La información de playas procede de fuentes oficiales (Náyade/Ministerio de Sanidad, MITECO, Censo de Vertidos Tierra-Mar del Gobierno de Canarias) y de prensa local — estas consultas no llevan datos tuyos.

Cómo dejar de recibir datos / borrar el token

Desactiva las notificaciones en los ajustes de Android o desinstala la app: el token deja de recibir avisos y los tokens inválidos se purgan automáticamente del servidor.

Contacto

Es un proyecto personal de código abierto. Para cualquier duda de privacidad puedes abrir un issue en github.com/ayozegr05/checkcoast-tenerife.
